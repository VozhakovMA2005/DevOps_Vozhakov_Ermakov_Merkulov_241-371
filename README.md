# AudFond

Приложение для учёта закрепления площадей за подразделениями.

---

## Структура репозитория

В корне проекта находятся три основные папки:

| Папка | Назначение |
|---|---|
| **`document/`** | Документация проекта: техническое задание, проектные решения, отчёты и сопутствующие материалы. |
| **`project/`** | Файлы проекта: исходный код, конфигурации, миграции, тесты и всё, что относится к реализации. |
| **`program description/`** | Описание программы: описание функциональности, сценарии работы и примеры использования, схемы БД и API. |

---

## Кратко о проекте

**AudFond** — учёт закрепления площадей за подразделениями: корпуса, виды помещений, помещения, подразделения и закрепления с контролем суммы закреплённых площадей по интервалам.

## Быстрый старт

```bash
git clone git@github.com:<логин>/audfond.git
cd audfond
docker compose up -d --build
```

Подробности запуска и настройки — в документации в папке [`document/`](./document).

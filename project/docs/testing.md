# Тесты

```bash
make test        # в контейнере
make test-cov    # с отчётом о покрытии
```

Локально, если есть доступная база:

```bash
TEST_ADMIN_DSN="postgresql://postgres@127.0.0.1:5432/postgres" python3 -m pytest
```

## Почему на настоящем PostgreSQL

Проверяются вычисляемый столбец `volume`, `CHECK`-ограничения, перечисления и
поведение внешних ключей. На SQLite ничего этого нет, и тесты проверяли бы не
то, что работает в бою. Для каждого прогона создаётся отдельная база, после —
удаляется.

## На что смотреть в первую очередь

`test_rule_d5.py` — ключевое правило в чистом виде, без базы и HTTP: видно, что
именно считается и как округляется. `test_rooms.py::TestRuleD5` — то же правило
на живой базе во всех трёх местах, где данные могут измениться.

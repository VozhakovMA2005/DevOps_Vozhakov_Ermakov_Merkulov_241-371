# AudFond — аудиторный фонд университета

Приложение для автоматизации контроля аудиторного фонда университета.
Техническое задание: **А.В.00001-01 33 01-1**.

Команда: Вожаков М. А., Ермаков М. А., Меркулов Г. С.

Стек: Python 3.12, FastAPI, SQLAlchemy 2 + Alembic, PostgreSQL 17.

## Запуск

```bash
cp .env.example .env
make up          # приложение и база в контейнерах
make migrate     # схема базы
```

Служебные адреса: `/healthz`, `/readyz`, `/version`.

Развёртывание без контейнеров — `make setup && make run`, служба systemd
описана в `deploy/audfond.service`.

## Состояние

Каркас, схема базы и развёртывание. Справочники и вход появятся
в следующих задачах.

## Конфигурация

Вся настройка — через переменные окружения (ТЗ 4.6), список в `.env.example`.
Секретов в репозитории нет. Две переменные обязательны, без них приложение не
стартует: `DATABASE_URL` и `JWT_SECRET`.

```bash
cp .env.example .env
python3 -c "import secrets; print(secrets.token_urlsafe(48))"   # в JWT_SECRET
```
